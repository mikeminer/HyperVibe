# HyperVibe by pappardelle.eth 🚀

**HyperVibe وكيل ذكاء اصطناعي يتداول تلقائياً على Hyperliquid نيابةً عنك.**

أنت تخبره بما تريد فعله. يحلل الأسواق، يقترح الصفقات، وينتظر موافقتك قبل تنفيذ أي أمر. لا تتم أي صفقة دون موافقتك الصريحة.

> 🇮🇹 [Versione italiana → README.md](./README.md) | 🇬🇧 [English → README.en.md](./README.en.md)

---

## ماذا يفعل تحديداً؟

- **يحلل** أسواق العملات المشفرة 24/7 باستخدام مؤشرات تقنية حقيقية (RSI, MACD, Bollinger Bands)
- **يقترح صفقات** مع تفسير كامل: لماذا الدخول، أين وضع وقف الخسارة، أين جني الأرباح
- **ينتظر موافقتك** — كل أمر يظهر كبطاقة مع زر موافقة / رفض
- **يدير المراكز** تلقائياً مع أوامر وقف الخسارة وجني الأرباح الأصلية على البورصة
- **يبحث عن استراتيجيات** عبر اختبار خلفي تلقائي بالذكاء الاصطناعي على أي عقد دائم في Hyperliquid
- **يتعلم** بتسجيل كل صفقة مع تفسيرها في يومية التداول

## Autotrade Strategy Research 🔬

يدمج [autotrade](https://github.com/rv64m/autotrade) في HyperVibe كخط أنابيب بحث تلقائي.

```
autotrade (اختبار خلفي بالذكاء الاصطناعي) ──▶ ملف إشارة JSON ──▶ اقتراح صفقة ──▶ موافقتك ──▶ Hyperliquid
```

### سير العمل الكامل من الدردشة

**الخطوة 1 — ابدأ البحث:**
```
ابحث عن استراتيجية على SOL، الإطار الزمني 1h، 20 تكراراً
```
> يرد الوكيل: *"بدأ البحث على SOL (1h، 20 تكراراً). الوقت المقدر: ~50 دقيقة."*

**الخطوة 2 — حمّل النتيجة:**
```
أرني نتيجة البحث على SOL
```
> يعرض الوكيل: عامل الربح، الحد الأقصى للسحب، Sharpe، نسبة الربح، SL%، TP%، الرافعة، الحجم.

**الخطوة 3 — اقتراح الصفقة:**
```
اقترح الصفقة بناءً على إشارة SOL
```
> تظهر البطاقة مع زر **موافقة / رفض**.

**الخطوة 4 — توافق ← الصفقة تذهب مباشرة.**

### الأطر الزمنية والتاريخ المتاح على Hyperliquid

| الإطار الزمني | التاريخ المتاح |
|--------------|----------------|
| 15m | ~52 يوماً |
| 1h | ~208 أيام |
| 4h | ~833 يوماً |
| 1d | ~13 سنة |

## Playbooks 📋 — استراتيجيتك في التداول

Playbook يشبه **بطاقة تعليمات** تعطيها للوكيل مع كل ما يحتاج معرفته عنك وعن استراتيجيتك.

الوكيل يقرأ هذه البطاقة **في كل مرة يستيقظ** — لذا يتصرف دائماً بما يتناسب مع استراتيجيتك.

**Playbooks المتاحة في المتجر:**

| Playbook | الاستراتيجية |
|---|---|
| HYPE Momentum Scalp | صفقات سريعة على HYPE، حسابات صغيرة |
| Funding Rate Arbitrage | استغلال معدلات التمويل المتطرفة، محايد للسوق |
| BTC/ETH Trend Follower | صفقات سوينغ كبرى، 1-5 أيام |
| OpenClaw Autonomous | خط أنابيب تلقائي كامل |
| Top Mover Breakout | مسح صباحي، اختراق اليوم |
| HYPE Fee Monitor & Burn Predictor | مراقبة رسوم HAF على السلسلة، إشارات BOUNCE_HIGH / BURN_SPIKE |
| **Autotrade Strategy Research** ⭐ | بحث تلقائي عن الاستراتيجيات عبر اختبار خلفي بالذكاء الاصطناعي |

## Skills 🛠️ — تقنيات الوكيل

Skill هي **دليل تقني** تعلمه للوكيل مرة واحدة. الفرق: **Playbook** يقول *ماذا* تفعل، **Skill** يقول *كيف* تفعله.

**Skills المتاحة في المتجر:**

| Skill | ما تفعله |
|---|---|
| OpenClaw 3-Agent Pipeline | تحليل Monte Carlo + معيار Kelly + سلم الخروج قبل كل صفقة |
| Funding Rate Filter | متى تتجنب الصفقات بسبب معدل تمويل مرتفع |
| Unified Account Sizing | قواعد تحديد حجم المركز لحساب Unified |
| HYPE Momentum | قواعد خاصة لتداول HYPE |
| Drawdown Guard | متى تتوقف عن التداول لحماية رأس المال |

## التثبيت — أمر واحد فقط

افتح **موجه الأوامر (CMD)** والصق هذا:

```
powershell -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/mikeminer/HyperVibe/main/installer.bat' -OutFile installer.bat" && installer.bat
```

**كيف تفتح CMD:** اضغط **Windows + R** ← اكتب `cmd` ← اضغط Enter ← الصق الأمر.

المثبّت v3.2 يقوم بكل شيء تلقائياً:

1. يثبت Node.js إذا لم يكن لديك
2. يثبت Git إذا لم يكن لديك
3. يحمّل HyperVibe من GitHub (مع submodule autotrade)
4. يسأل إذا كنت تريد تثبيت وحدة **Autotrade Strategy Research** *(اختياري، ~200MB)*
5. يثبت Claude Code CLI لحلقة الذكاء الاصطناعي *(إذا اخترت Autotrade)*
6. اختيار محرك الذكاء الاصطناعي: Anthropic API، أو Qwen 2.5 14B محلي، أو Gemma 4 26B محلي
7. يسألك عن بيانات الاعتماد (API key، عنوان المحفظة، المفتاح الخاص)
8. يشغل البرنامج ويفتح المتصفح

## الأمان

- مفتاحك الخاص **لا يغادر جهاز الكمبيوتر الخاص بك أبداً**
- كل أمر يتطلب موافقتك الصريحة
- لا تتم أي صفقة تلقائياً دون أن تضغط على زر الموافقة
- جميع البيانات محفوظة محلياً فقط
- لـ Autotrade: استخدم دائماً **API wallet** من Hyperliquid، وليس مفتاحك الرئيسي
