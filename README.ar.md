# HyperVibe 🚀

**HyperVibe وكيل ذكاء اصطناعي يتداول بشكل مستقل على Hyperliquid نيابةً عنك.**

أنت تخبره بما تريد. يحلل الأسواق، يقترح الصفقات، وينتظر موافقتك قبل تنفيذ أي أمر. لا تنطلق أي صفقة دون موافقتك الصريحة.

---

## ماذا يفعل بالتحديد؟

* **يحلل** أسواق العملات المشفرة على مدار الساعة باستخدام مؤشرات تقنية حقيقية (RSI، MACD، Bollinger Bands)
* **يقترح صفقات** مع تفسير كامل: لماذا الدخول، أين وضع وقف الخسارة، أين أخذ الربح
* **ينتظر موافقتك** — كل أمر يظهر كبطاقة بزر موافقة / رفض
* **يدير المراكز** تلقائياً مع وقف الخسارة وجني الأرباح على المنصة
* **يتعلم** بتسجيل كل صفقة مع تفسيرها في السجل

تتحدث معه في الدردشة كما لو كان متداولاً خبيراً:

> *"حلل HYPE على الرسم البياني 4 ساعات وأخبرني إن كانت هناك فرصة"*
> *"افتح مركزاً طويلاً على BTC مع وقف عند $90,000"*
> *"راقب مراكزي كل ساعة"*

## محرك Tri-Hybrid 🧠 — توجيه ذكي للذكاء الاصطناعي

يتضمن HyperVibe محرك ذكاء اصطناعي بثلاثة مستويات يوجّه كل طلب إلى النموذج الأقل تكلفة القادر على الاستجابة بجودة كافية.

```
كل سؤال → Value Score → المستوى المختار
────────────────────────────────────────
score < 0.30  →  LLaMA محلي   (مجاني، فوري)
score < 0.60  →  OpenAI GPT   (سريع، اقتصادي)
score ≥ 0.60  →  Anthropic Claude (أعلى جودة)
```

يقيس **value score** أربعة أبعاد للسؤال:

| المقياس | الوزن | ما يقيسه |
|---|---|---|
| `reasoning_depth` | 40% | مقدار التفكير الذي تتطلبه الإجابة |
| `uncertainty` | 30% | الغموض والأسئلة المفتوحة |
| `impact` | 20% | الأهمية المالية / التشغيلية |
| `complexity` | 10% | التعقيد التقني واللغوي |

إذا كانت **ثقة** استجابة النموذج المختار منخفضة، يتصاعد النظام تلقائياً إلى المستوى الأعلى. يُسجَّل تكلفة كل طلب في `tri_hybrid_engine/logs/engine.jsonl`.

### جسر HTTP (التكامل الأصلي مع HyperVibe)

يعرض الجسر نقطة نهاية `/v1/messages` متوافقة مع Anthropic SDK. يوجّه HyperVibe إلى `http://localhost:3002` بدلاً من `api.anthropic.com` — دون أي تغييرات في كود Node.js.

```
HyperVibe (Node.js :3001)
        │
        │  POST /v1/messages
        ▼
Tri-Hybrid Bridge (:3002)
        │
        ├─ LLaMA  (Ollama محلي)
        ├─ OpenAI GPT
        └─ Claude
```

**نقاط النهاية المتاحة:**

| النقطة | الوصف |
|---|---|
| `POST /v1/messages` | متوافق مع Anthropic — يستخدمه HyperVibe |
| `GET  /v1/health` | حالة المستويات الثلاثة |
| `GET  /v1/stats` | إحصائيات الجلسة والتكاليف |
| `POST /v1/score` | حساب value score لأي سؤال |

## Playbooks 📋 — استراتيجية التداول الخاصة بك

Playbook هو **ورقة تعليمات** تعطيها للوكيل تحتوي على كل ما يحتاج معرفته عنك وعن استراتيجيتك:

> *"مرحباً، أريد التداول على HYPE. لا تخاطر أبداً بأكثر من 1% لكل صفقة. استخدم دائماً وقف الخسارة. إذا خسرت أكثر من 3% في يوم واحد، توقف عن التداول."*

يقرأ الوكيل هذه الورقة **في كل مرة** يستيقظ فيها.

**Playbooks المتاحة في Playbook Store:**

| Playbook | الاستراتيجية |
|---|---|
| HYPE Momentum Scalp | صفقات HYPE السريعة، تحيز شراء، حسابات صغيرة |
| Funding Rate Arbitrage | استغلال معدلات التمويل المتطرفة، محايد للسوق |
| BTC/ETH Trend Follower | تداول سوينج كبير، 1-5 أيام |
| OpenClaw Autonomous | خط أنابيب تلقائي كامل |
| Top Mover Breakout | مسح صباحي، اختراق اليوم |

## التثبيت — أمر واحد فقط

افتح **موجه الأوامر (CMD)** والصق هذا:

```
powershell -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/mikeminer/HyperVibe/main/INSTALL_v3.4.bat' -OutFile INSTALL_v3.4.bat" && INSTALL_v3.4.bat
```

يتولى البرنامج كل شيء تلقائياً:

1. تثبيت Node.js إذا لم يكن موجوداً
2. تثبيت Git إذا لم يكن موجوداً
3. تحميل HyperVibe من GitHub
4. طلب بيانات الاعتماد (مفتاح API، المحفظة، المفتاح الخاص)
5. **اختيار محرك الذكاء الاصطناعي:** Anthropic / Qwen محلي / Gemma محلي / **Tri-Hybrid** ← جديد
6. تشغيل البرنامج وفتح المتصفح
