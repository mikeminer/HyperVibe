# HyperVibe 🚀

**HyperVibe وكيل ذكاء اصطناعي يتداول تلقائياً على Hyperliquid نيابةً عنك.**

أنت تخبره بما تريد فعله. يحلل الأسواق، يقترح الصفقات، وينتظر موافقتك قبل تنفيذ أي أمر. لا تتم أي صفقة دون موافقتك الصريحة.

---

## ماذا يفعل تحديداً؟

- **يحلل** أسواق العملات المشفرة 24/7 باستخدام مؤشرات تقنية حقيقية (RSI, MACD, Bollinger Bands)
- **يقترح صفقات** مع تفسير كامل: لماذا الدخول، أين وضع وقف الخسارة، أين جني الأرباح
- **ينتظر موافقتك** — كل أمر يظهر كبطاقة مع زر موافقة / رفض
- **يدير المراكز** تلقائياً مع أوامر وقف الخسارة وجني الأرباح الأصلية على البورصة
- **يتعلم** بتسجيل كل صفقة مع تفسيرها في يومية التداول

تتحدث معه في الدردشة كمتداول محترف:
> *"حلل HYPE على الرسم البياني 4 ساعات وأخبرني إذا كانت هناك فرصة"*
> *"افتح صفقة شراء على BTC مع وقف خسارة عند $90,000"*
> *"راقب مراكزي كل ساعة"*

---

## Playbooks 📋 — استراتيجيتك في التداول

Playbook يشبه **بطاقة تعليمات** تعطيها للوكيل مع كل ما يحتاج معرفته عنك وعن استراتيجيتك:

> *"مرحباً، أريد التداول على HYPE. لا تخاطر بأكثر من 1% لكل صفقة. استخدم دائماً وقف الخسارة. إذا خسرت أكثر من 3% في يوم، توقف عن التداول."*

الوكيل يقرأ هذه البطاقة **في كل مرة يستيقظ** — لذا يتصرف دائماً بما يتناسب مع استراتيجيتك دون أن تحتاج لشرح كل شيء من جديد.

يمكنك امتلاك عدة Playbooks: واحد لـ HYPE، آخر لـ BTC، آخر لمراجحة معدل التمويل.

**Playbooks المتاحة في المتجر:**
| Playbook | الاستراتيجية |
|---|---|
| HYPE Momentum Scalp | صفقات سريعة على HYPE، حسابات صغيرة |
| Funding Rate Arbitrage | استغلال معدلات التمويل المتطرفة |
| BTC/ETH Trend Follower | صفقات سوينغ كبرى، 1-5 أيام |
| OpenClaw Autonomous | خط أنابيب تلقائي كامل |
| Top Mover Breakout | مسح صباحي، اختراق اليوم |

## Skills 🛠️ — تقنيات الوكيل

Skill هي **دليل تقني** تعلمه للوكيل مرة واحدة. في كل مرة يحتاج لفعل ذلك الشيء، يفتح الدليل ويتبعه بدقة.

الفرق: **Playbook** يقول *ماذا* تفعل، **Skill** يقول *كيف* تفعله.

**Skills المتاحة في المتجر:**
| Skill | ما تفعله |
|---|---|
| OpenClaw 3-Agent Pipeline | تحليل Monte Carlo + معيار Kelly + سلم الخروج قبل كل صفقة |
| Funding Rate Filter | متى تتجنب الصفقات بسبب معدل تمويل مرتفع |
| Unified Account Sizing | قواعد تحديد حجم المركز لحساب Unified |
| HYPE Momentum | قواعد خاصة لتداول HYPE |
| Drawdown Guard | متى تتوقف عن التداول لحماية رأس المال |

## التثبيت — أمر واحد فقط

افتح **موجه الأوامر (CMD)** والصق هذا:

```
powershell -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/mikeminer/HyperVibe/main/HyperVibe.bat' -OutFile HyperVibe.bat" && HyperVibe.bat
```

**كيف تفتح CMD:** اضغط **Windows + R** ← اكتب `cmd` ← اضغط Enter ← الصق الأمر.

المثبت يقوم بكل شيء تلقائياً:
1. يثبت Node.js إذا لم يكن لديك
2. يثبت Git إذا لم يكن لديك
3. يحمّل HyperVibe من GitHub
4. يسألك عن بيانات الاعتماد (API key، عنوان المحفظة، المفتاح الخاص)
5. يشغل البرنامج ويفتح المتصفح
